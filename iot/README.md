# 🔌 EcoCity Guardian — Módulo IoT & Sensoriameto

Este módulo contém a simulação telemétrica do sensor de nível de água para prevenção de enchentes e zeladoria urbana.

## 🛠️ Componentes Simulados
- **Placa:** ESP32 DevKit v1
- **Sensor:** Sensor Ultrassônico HC-SR04 (Medição do nível de água no bueiro/rio)
- **Atuador:** LED Alerta de Emergência

## 🚀 Como Executar a Simulação
1. Acesse a plataforma [Wokwi](https://wokwi.com/).
2. Abra um novo projeto para **ESP32**.
3. Importe os arquivos `sketch.ino`, `diagram.json` e `libraries.txt`.
4. Inicie a simulação para enviar telemetrias git add iot/HTTP para a API da IA.
